# Singbox-Config

个人自用的 sing-box 配置模板及 Sub-Store 节点注入脚本。

## 内容

- config.json 配置模板：包含 DNS、入站、出站、路由规则及规则集等配置。
- script.js 脚本：从指定订阅读取节点，并转换为 sing-box 格式注入配置。

## 使用方法

1. 在 Sub-Store 中导入或新建配置文件，放入仓库中的 sing-box 配置模板。
2. 添加仓库中的节点注入脚本。
3. 在脚本操作的参数区域添加参数：

   | key | value |
   | --- | --- |
   | `subscription` | Sub-Store 中的订阅名称 |

4. 将 `subscription` 的值设置为需要注入的订阅名称，然后预览并检查生成的 sing-box 配置。
5. 将生成的配置导入 sing-box。

## 节点注入逻辑

脚本会将指定订阅中的节点注入到 sing-box 配置：

- **🚀节点选择**：订阅节点添加在 **🎈自动选择** 之前，可手动选择节点。
- **🎈自动选择**：订阅节点加入自动测速列表。

脚本会按节点 tag 去重，并保留模板中的其他配置。

## 说明

本仓库配置仅供个人使用参考。使用前请根据自己的网络环境和 Sub-Store 订阅名称修改参数，并确认生成的配置能够正常运行。
